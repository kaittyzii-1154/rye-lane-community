# [Rye Lane — Look Again](https://kaittyzii-1154.github.io/rye-lane-community/index.html)

## [Open the Rye Lane portfolio website ↗](https://kaittyzii-1154.github.io/rye-lane-community/index.html)

A community website for exploring Rye Lane through drawings, photographs, local news, interviews and connected walks.

## Preview

Run `python3 preview_server.py`, then open http://127.0.0.1:8765.

## Pages

- Home
- Explore the Street and Shops & Neighbours
- Everyday Stories and Look & Walk
- Community News, Local Connections and Street History
- About This
- Your View
- City Walks: three connected sections

News has a saved copy for static hosting. Live news checks need the Python preview server. Photos and visited stops are stored on the visitor’s device.

This archive contains the current version only, without earlier experiments or preview screenshots.
